## 🛠️ Tech Stack

### Frontend Architecture
| Layer | Tech | Description |
| --- | --- | --- |
| **Framework** | React + Vite | Lightning-fast HMR and highly optimized production builds. |
| **Styling** | Tailwind CSS | Mobile-first approach, fully responsive out-of-the-box. |
| **Animations** | GSAP & Framer | Fluid, GPU-accelerated micro-interactions across components. |
| **State** | Context API | Efficient global state management without heavy boilerplate. |
| **Icons** | Lucide React | Clean, scalable vector graphics. |

### Backend & Real-time Edge
| Layer | Tech | Description |
| --- | --- | --- |
| **Real-time** | Socket.io | Bi-directional event-based communication for live chat. |
| **Payments** | Razorpay | Integrated logic for seamless peer-to-peer transaction scaling. |

## 🎨 Design Philosophy

MentorVault's interface is intentionally designed to evoke focus and intent.

* **Base Canvas**: Deep, immersive black (`#050505`) creates a distraction-free aesthetic.
* **Elevated Layers**: Floating elements and cards use an ultra-dark gray (`#0a0a0a`), framed by razor-thin glowing borders (`border-white/5`), generating depth without heavy drop-shadows or blurs.
* **Emphasis**: A sharp crimson red acts as the sole primary accent color, guiding the user's eye instantly to actionable areas and vital statistics.

## 🚀 Getting Started

Follow these steps to run the MentorVault frontend locally on your machine.

### Prerequisites
Make sure you have Node.js and npm (or yarn/pnpm) installed.

### Installation & Launch

1. **Clone the repository:**
   ```bash
   git clone https://github.com/your-username/MentorVault.git
   cd MentorVault/front-end/mentorfont-end
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the Vite development server:**
   ```bash
   npm run dev
   ```

4. **Prepare for takeoff:** 
   Open your browser and navigate to `http://localhost:5173`.
